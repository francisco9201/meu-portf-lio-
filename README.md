# Francisco.dev — portfólio reestruturado

## Estrutura
- `index.html` — página inicial
- `login.html` — login demonstrativo com sessão local
- `projetos.html` — quiz interativo
- `midia.html` — mídia do projeto Naruto Vision
- `css/style.css` — estilos compartilhados
- `js/app.js` — interações compartilhadas
- `assets/` — imagens e ícones

## Recursos
- Tema claro/escuro
- Ligar/desligar do site com `localStorage`
- Login demonstrativo com sessão local
- Logout
- Navegação ativa
- Typewriter
- Animações de entrada
- Cards com efeito 3D
- Barras de conhecimento animadas
- Botão voltar ao topo
- Quiz com 8 questões e pontuação automática
- Redes sociais clicáveis
- Imagens locais sem dependência de CDN
- Layout responsivo

## Observação sobre login
É uma implementação apenas de front-end para fins de portfólio/estudo. Não é um sistema de autenticação seguro para produção e não deve receber senhas reais.
