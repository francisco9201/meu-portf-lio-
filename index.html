Sobre mim

Uma transição construída com estudo e prática

Minha trajetória profissional começou na área gastronômica, onde desenvolvi disciplina, organização, trabalho em equipe, atenção aos detalhes e capacidade de lidar com ambientes de alta demanda. Hoje, estou direcionando essas competências para uma nova etapa profissional na tecnologia.

Atualmente curso Engenharia de Software na Estácio, no 4º semestre, com previsão de conclusão em dezembro de 2028. Ao longo da graduação venho estudando lógica de programação, orientação a objetos, estruturas de dados, banco de dados, SQL, engenharia de software e desenvolvimento de sistemas.

Na prática, venho desenvolvendo projetos e exercícios com Java, Python, JavaScript, HTML, CSS e PostgreSQL, além de utilizar Git e GitHub para versionamento. Meu objetivo é transformar esse aprendizado em experiência profissional e realizar a transição para a área de desenvolvimento.

Objetivo

Busco uma oportunidade de estágio ou posição inicial em desenvolvimento, especialmente em backend Java, para aprender com uma equipe, contribuir com responsabilidade e continuar evoluindo tecnicamente.
